# Analog Modulation and Demodulation

## Introduction
This project focuses on the analysis, implementation, and evaluation of classical analog modulation and demodulation techniques using MATLAB. The objective is to examine signal characteristics in the time and frequency domains and investigate the effects of different modulation schemes on signal transmission and reconstruction.

## Input Signals
The project uses four audio signals:
- `female.wav` — Female voice
- `male.wav` — Male voice
- `guitar.wav` — Guitar audio
- `piano.wav` — Piano audio

## Implemented Techniques
The MATLAB implementation covers the following analog modulation schemes:
- Amplitude Modulation (AM)
- Double-Sideband Suppressed-Carrier (DSB-SC)
- Single-Sideband Modulation (SSB)
- Vestigial-Sideband Modulation (VSB)
- Frequency Modulation (FM)
- Phase Modulation (PM)

## Analysis and Processing
The project includes signal analysis in the time and frequency domains, power spectrum evaluation, modulation and demodulation, FIR filtering, and reconstruction of the original signals.

## Files
- `female.wav`, `male.wav`, `guitar.wav`, `piano.wav`: Input audio signals.
- `main.m`: MATLAB script for signal processing, modulation, and demodulation.

## Requirements
- MATLAB
- Input audio files in WAV format

## How to Run
1. Clone or download this repository.
2. Place all input audio files in the appropriate working directory.
3. Open the MATLAB script.
4. Run the script to perform the analysis and modulation/demodulation processes.
